# zavod.guru — прототипы UI

Кликабельные HTML-прототипы интерфейсов внутренней CRM zavod.guru. Делаются для UX-критичных фич до реализации: продукт-овнер показывает, как должен выглядеть интерфейс, разработчик натягивает функционал.

Каждый прототип — один самодостаточный HTML-файл, открывается в браузере без сборки.

## Прототипы

| Файл | Что показывает |
|---|---|
| [layout-prototype.html](layout-prototype.html) | Новый лайаут: верхнее меню со звёздами и мега-меню «Все инструменты», строка выбора проекта, сворачиваемый левый сайдбар с вкладками проекта. Сквозной модуль таблиц-списков на всех страницах разделов (Проекты, Домены и типовые): сортировка по типу данных, фильтры по значениям/датам/числам в меню заголовка, чипы фильтров, поиск, страницы, управление столбцами, экспорт CSV/XLSX, выбор строк и массовые действия, быстрые фильтры |
| [cost-report.html](cost-report.html) → `layout-prototype.html#/cost-report` | Отчёт по себестоимости API: сводная таблица с 2 уровнями группировки по команде / ответственному / провайдеру / модели / шаблону, раскрытие до проектов, провайдер и модель в отдельных столбцах, карточки «Потрачено за период», «Средняя стоимость 1 проекта», «Всего проектов», периоды, фильтры, поиск, управление колонками (показ, порядок перетаскиванием), экспорт CSV, график динамики (столбики по дням/неделям/месяцам, цвет — группа 1-го уровня) |
| [projects-report.html](projects-report.html) → `layout-prototype.html#/projects-report` | Сводный отчёт по проектам на том же движке сводной таблицы (`makePivot`): группировка в 2 уровня по команде / ответственному / схеме / шаблону / ПП ссылке / html lang / бренду / слоту, столбцы проекта и GSC, период по дате запуска, карточки «Запущено сайтов», «Показы / клики», «Проект с самым большим трафиком», график динамики (клики / показы / запуски) |

Опубликовано на GitHub Pages: https://serjnsk.github.io/zavod-prototype/
