# zavod.guru — прототипы UI

Кликабельные HTML-прототипы интерфейсов внутренней CRM zavod.guru. Делаются для UX-критичных фич до реализации: продукт-овнер показывает, как должен выглядеть интерфейс, разработчик натягивает функционал.

Каждый прототип — один самодостаточный HTML-файл, открывается в браузере без сборки.

## Прототипы

| Файл | Что показывает |
|---|---|
| [layout-prototype.html](layout-prototype.html) | Новый лайаут: верхнее меню со звёздами и мега-меню «Все инструменты», строка выбора проекта, сворачиваемый левый сайдбар с вкладками проекта. Сквозной модуль таблиц-списков на всех страницах разделов (Проекты, Домены и типовые): сортировка по типу данных, фильтры по значениям/датам/числам в меню заголовка, чипы фильтров, поиск, страницы, управление столбцами, экспорт CSV/XLSX, выбор строк и массовые действия, быстрые фильтры |

Опубликовано на GitHub Pages: https://serjnsk.github.io/zavod-prototype/
